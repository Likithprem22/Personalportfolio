Selected Work

My Portfolio

Hallucination Localization in Code Translation Ongoing

Token-level system to pinpoint knowledge-conflicting hallucinations in LLM-generated Java→C# translations using entropy signals from StarCoder2. Building an annotated dataset labeled with exact line/token indices, evaluated with precision, recall & Top-K accuracy.

Python · StarCoder2 · LLMs · Dataset Annotation

Hepatic Fibrosis Risk Prediction

Multi-task deep learning model predicting hepatic fibrosis risk from EHR data, benchmarked against a nested XGBoost baseline on a 38,438-patient NAFLD cohort. Reached 81.90% sensitivity and 0.91 ROC-AUC on noisy clinical labels.

Python · PyTorch · XGBoost · Clinical Data

NITC Assessment Management System

MERN platform for academic evaluations at NIT Calicut — NITC-email faculty auth, CSV/Excel bulk candidate & evaluator import, random/manual evaluator mapping, auto seating arrangement, and score-entry dashboards.

React.js · Node.js · Express.js · MongoDB

LogSentinel

Autonomous log-monitoring agent that uses utility-based reasoning over structured tool outputs to detect abnormal system behavior, with traceable step-by-step execution and severity-categorized alerts (INFO/WARN/ERROR).

Python · Intelligent Agent Design · Utility-Based Reasoning

System Privilege Security Lab

Explored how access and privilege are controlled across three system layers — container users in Docker, file permissions in Linux, and program control-flow in C. Set up isolated environments to test each layer, tracing execution to see how unchecked input could hijack a running program.

Docker · Linux · C · GDB · Bash

Driver Fatigue Detection

Combines Local Binary Pattern (LBP) texture analysis with CNNs to detect driver fatigue cues like yawning from facial images, improving road safety.

Machine Learning · Deep Learning · LBP · CNN
